# Expression Tree Calculator

Welcome!

This project is a calculator that evaluates mathematical expressions using an expression tree and a stack-based approach. The goal is to deepen my understanding of data structures (such as trees and stacks) and object-oriented programming in Java.

# Features

Parses mathematical expressions and builds a binary expression tree.

Evaluates expressions using post-order traversal.

Supports basic arithmetic operations and more complex ones (+, -, *, /, ²).

Handles operator precedence correctly.
